Running the code is straightforward. The repository contains the file cp1.py. The user should navigate to and run the file as they would any other file. A common way to run the script would be to navigate to the terminal and enter “python cp1.py”, but the process may differ based on the user’s environment. 
The script will then prompt the user for the desired size of the grid. The solution was designed for a grid size of 5 x 5, but the user can scale the size up as desired. Grid sizes of 1 x 1 and 2 x 2 should not be considered since there will be 2n robots on the grid for a size of n x n. The same goes for an overly large n.
